How this console works

Peers count as online from their UDP heartbeat to port 21116, keyed on the RustDesk ID carried inside the packet rather than the source IP — everything behind a NAT gateway shares one address, so IP alone cannot tell two clients apart.

Machine names come from the machine's own vault record, matched on its RustDesk ID. Otherwise the console asks the address directly (NetBIOS, then the name inside the SMB handshake), then reverse DNS. Hover a name to see which one answered.

Logged on is reported by each machine itself, at every logon and every 5 minutes. An older report is dimmed and shows its age. A missing report can mean the task has not been installed, cannot reach the vault, or is failing. The Reporting column distinguishes missing, stale, invalid, and owner-rejected reports.

Passwords are read from the vault share only when you press reveal, are never part of this page or the refresh feed, and re-mask after 20 seconds. Every reveal is recorded in the audit log.

Connect opens the RustDesk client on this computer. The password is deliberately not passed in the link, so it never lands in browser history.
